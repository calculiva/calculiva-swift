# calculiva-swift

Home improvement estimators from [Calculiva](https://calculiva.com/), as a Swift package:
mulch, topsoil and fill, and sod. Each result is a planning quantity (volume, bags, bulk,
pallets, pieces, weight, trips), computed with the method described at
<https://calculiva.com/how-we-calculate/>.

This package is a line-by-line port of the Go module
[`github.com/calculiva/calculiva-go`](https://github.com/calculiva/calculiva-go), version 0.3.0.
Its tests replay `Tests/CalculivaTests/vectors.json`, a set of test vectors generated by running
that Go module: same inputs, same outputs, same error fields and messages.

Swift 5.9 or later, Linux and macOS. No dependency outside Foundation.

```swift
// Package.swift
.package(url: "https://github.com/calculiva/calculiva-swift", from: "0.3.0")
```

## Example

```swift
import Calculiva
import Foundation

// Two 40 x 3 ft beds topped up from 1 in to 3 in, bought in 2 cu ft bags.
let bed = Mulch.Area(id: "front-bed", kind: .bed(l: 40 * foot, w: 3 * foot, count: 2),
                     target: 3 * inch, existing: 1 * inch)
let plan = try Mulch.newPlan(Mulch.Input(areas: [bed], bagSize: 2), rules: Mulch.newRules())
print(String(format: "%.1f cu ft, %.0f bags", plan.totals.cuFt, plan.buy.bags ?? 0))
// 40.0 cu ft, 20 bags
```

All lengths are millimetres (`inch` = 25.4, `foot` = 304.8). Invalid input throws an
`InputError` that names the offending field.

## What is in it

| Namespace | Functions | Calculator |
|---|---|---|
| `Mulch` | `newRules`, `newPlan`, `newRingGuidance`, `checkRing`, `coverage` | [Mulch calculator](https://calculiva.com/landscaping/mulch-calculator/) |
| `Soil` | `Rules(weights:)`, `newPlan`, `areaOf`, `bagCuFt`, `coverage` | [Soil calculator](https://calculiva.com/landscaping/soil-calculator/) |
| `Sod` | `newRules`, `newInput`, `newPlan`, `layRect`, `formatTable` | [Sod calculator](https://calculiva.com/landscaping/sod-calculator/) |

Every constant is a named value whose documentation gives its data sheet, the public source it
was read on and the date it was verified, exactly as in the Go module. Material weights, bag and
wheelbarrow sizes and sod allowances are not shipped: they are inputs of the user. The constants
registry of the Go module (`ConstantsCSV`) is not part of this package; the sources are listed at
<https://calculiva.com/data-sources/>.
